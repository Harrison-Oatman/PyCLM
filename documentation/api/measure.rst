Measurement toolbox (``pyclm.core.measure``)
============================================

Per-object measuring, per-track memory and painting for pattern methods;
see the toolbox section of :doc:`../custom_pattern_methods`. ``Regions``,
``PerTrack`` and ``nuclear_cytosolic_ratio`` are also importable from
``pyclm``.
