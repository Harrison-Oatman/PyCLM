# Proposals

Proposed changes to `lab.md` or a microscope note, one file each, named
`<date>_<short-topic>.md`. Each says what to change, why, and the evidence
(a run directory, a `run_record.json`, a log line).

Sessions add files here. An admin or the microscope owner accepts or
declines each one, applies it, and deletes the file. On a shared computer,
give users permission to create files in this folder but not to change
other files.
